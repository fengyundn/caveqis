# CAVEQIS 使用指南

一个可以在本机运行、也可以部署到 Python VPS 的中英文数学工具箱。网页、计算服务和公式字体均包含在本目录。根据你原有 `Theoretical Mechanics.py` 的方程求解和系数矩阵工作流扩展编写，原脚本没有改动。

## Windows 桌面版

下载并双击 `CAVEQIS-Setup-1.0.0-win-x64.exe`，按向导安装。之后可从桌面或开始菜单打开 CAVEQIS。安装包已包含显示界面和计算所需的组件。安装和使用均可离线，无需账号，也无需另外安装 Python、Node.js 或浏览器。桌面版的历史记录、偏好设置和图表保存在该 Windows 用户的应用数据中。

本版安装包目标为 Windows 10 / 11 x64，已在 Windows 11 x64 验证。安装包未签名，Windows 可能显示“未知发布者”。

## Windows 从源码运行

双击 **`启动工具箱.cmd`**，等待浏览器打开 **http://127.0.0.1:8765/**。计算期间保持启动窗口开启，按 `Ctrl+C` 可停止。若已在运行，启动脚本会直接打开现有页面。

需要 Python 3.10 或更新版本。工具箱使用项目自己的 `.venv` 环境。如果移动或复制到另一台电脑，请重新创建虚拟环境。缺少环境时，启动脚本会自动创建并安装依赖，首次安装需要网络。安装后计算和公式渲染均可离线使用，不需要 API 密钥、账号或外部 CDN。

请通过启动后的 HTTP 地址使用网页；不要直接双击 `static/index.html`，它需要连接本项目的 Python 计算服务。

手动启动：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app.py
```

默认仅监听本机。网页适配电脑和手机，默认使用英文，可在右上角切换中文或深浅色。工具箱包含可点击示例、结果复制、本地计算历史（最多保存 20 条、显示最近 5 条并可恢复）。浏览器禁用本地存储时仍可计算，但无法持久保存历史。

## 支持的运算

| 工具 | 功能 |
| --- | --- |
| 科学计算 | 一个数学输入框，支持四则、幂、根式、对数、三角函数、复数、化简、展开、因式分解等；保留 RAD/DEG，代入条件可写在同一框内 |
| 行列式 | 直接计算、余子式、代数余子式、按行或列展开、转置、乘积、数乘、矩阵幂和逆矩阵的行列式，或直接输入多个 `det(...)` 组合的表达式 |
| 矩阵 | 加减乘、右除 `A·B⁻¹`、数乘、整数幂、逆矩阵、转置、共轭转置、秩、迹、行最简形、零空间、特征值/向量、特征多项式、LU 分解、逐元素乘 |
| 积分 | 不定积分、定积分、无穷区间反常积分、最多三重积分、部分支持特殊函数解析结果；存在具体数值时同时尝试显示近似值 |
| 微分 | 一阶/高阶导数、混合偏导、全微分、梯度、Hessian 矩阵、指定点处求值 |
| 方程 | 自动求解、单变量符号求根、线性与非线性方程组、数值求根、矩阵方程、常微分方程和部分 Volterra 型积分方程。标量方程可组合行列式、微积分、极限、级数和初等函数 |
| 极限 | 左/右/双侧极限、无穷远处极限，可直接输入 `lim(f,x,a)` |
| 级数 | 级数展开（Taylor/Laurent，保留大 O 余项）、有限和、无穷级数求和及发散提示 |
| 日期计算 | 两日期间的总天数和日历间隔，按年、月、日加减日期 |
| 转换器 | 体积、长度、重量和质量、温度、能量、面积、速度、时间、功率、数据、压力、角度 |
| 图表 | 二维交互绘图，支持函数、隐式方程、不等式、参数曲线、极坐标、几何图形、统计图和滑块，提供分类符号和可点选的示例缩略图 |

有效数字可选 2、3、4、6 或 31，默认 6。从近似值的第一个非零数字起计数，例如设为 6 时，π 的近似值是 3.14159。精确结果保留原形式，数值求根先以较高精度求解，再按选定精度显示。单个表达式最多 1800 字符，矩阵最多 8×8，特征分析最多 5×5；请求体最多 24 KB，单次计算默认 12 秒。复杂度较高的问题可能超时，需要拆分计算。

## 可点击的运算符号

「计算」页按选中的类别显示专用符号。「方程」页汇集下表的符号。各模板都可手动输入。

| 页面 | 符号 | 输入模板 |
| --- | --- | --- |
| 积分 | ∫ 不定积分、∫ₐᵇ 定积分 | `∫(f,x)`、`∫(f,x,a,b)` |
| 微分与求导 | d/dx 一阶导数、∂ 偏导数、∂² 二阶偏导数、df 全微分 | `diff(f,x)`、`∂(f,x)`、`∂(f,x,2)`、`totaldiff(f,x,y)` |
| 极限 | lim | `lim(f,x,a)` |
| 级数 | ∑、∑∞、Tₙ | `∑(a(n),n,m,N)`、`∑(a(n),n,m,oo)`、`series(f,x,a,N)` |
| 行列式 | det | `det([1,2],[3,4])`，也可输入 `行列式（【1，2】，【3，4】）` |

选中函数再点符号可以将函数包入模板；先点符号，则光标进入第一个空位供填写。普通函数输入状态下，已输入的整个函数也会包入新模板。普通计算模式会自动切到“符号表达式计算”，直接按完整公式计算一次，避免重复积分或求导；方程模式插入符号后仍保留方程求解方式。

这些符号模板也支持自由输入，英文 integrate、diff、limit、sum、series 及相应中文别名仍可用。普通不定积分/定积分、普通求导/偏导、极限/级数页面会识别完整的对应符号模板。多项复合公式建议明确选择“符号表达式计算”。∫、∂、∑ 采用上表中带参数括号的输入格式，不解析任意手写排版或 LaTeX。

### 级数展开与级数求和

在「计算 → 级数」中可选级数展开、级数求和或直接输入级数表达式。

- **级数展开（Taylor / Laurent）**：给定函数、变量、展开点和阶数，返回局部展开及大 O 余项。例如 `series(exp(x),x,0,6)`。
- **级数求和（有限 / 无穷）**：给定通项、求和指标、上下限。整数上限求有限和，`oo` 或 `∞` 求无穷级数。也可直接点击 ∑ / ∑∞。

| 输入 | 结果 |
| --- | --- |
| `∑(1/n,n,1,5)` | `137/60` |
| `∑(1/n^2,n,1,∞)` | `pi^2/6` |
| `∑((1/2)^n,n,0,∞)` | `2` |
| `∑(1/n,n,1,∞)` | 正无穷，并提示可能发散 |

未能求出完整和时保留 Sum 符号；含参数的条件和会保留条件，不将其当成无条件成立的结果。

## 常用输入

```text
1/3 + 2/5                       精确分数
2^10 + sqrt(2)                  幂与平方根（也支持 **）
root(8,3)                       n 次根（取主值）
ln(e^2) + log(32,2)             自然对数与指定底数
sin(pi/6)                      弧度制三角函数
sin(30)                        科学计算切换为 DEG 后得到 1/2
2x + (x+1)(x-1)                 支持这些省略乘号形式
3+4*I                          复数，I 大写
```

常数为 `pi`、`e`/`E`、`I`、`oo`/`inf`。`pi`、`π` 都表示圆周率，`-oo` 为负无穷。三角函数在微积分工具中一律使用弧度制。

变量名可用中文、英文字母或混合名称，如 `力`、`温度1`、`Fx`，可带数字和单下划线；不能以数字或下划线开头，最多 24 字符。`Fx`、`力矩` 各自是一个变量，`x*y`、`力*距离` 才是两个变量的乘积。函数需要括号；输入的内容按数学语法解释，不执行 Python 代码、对象属性、导入或自定义函数。函数、常数名为保留名称，不能作为未知数。

### 点击按钮、自由输入与中英文

矩阵 A/B、积分、微分、方程和极限等数学输入框下方均有符号与函数按钮。每组按钮只操作它上方的输入框，支持在光标处插入、包裹选中的表达式和退格。`exp`、`sqrt`、`ln`、三角函数等既可以点选，也可以直接手动输入；其他函数在“更多函数与符号”中。变量名快捷面板只保留英文字母、希腊字母和退格符号，已移除中文词语、数字与分隔标点；多变量或混合偏导的逗号、冒号可手动输入。整数阶数面板继续提供数字。

侧栏依次是「计算」「方程」「日期计算」「转换器」「图表」和「使用指南」。使用指南可按运算类别查看，包含数学写法、用途和参数含义。共用键盘的符号与函数收录于「通用符号」。「计算」先选科学计算、行列式、矩阵、积分、微分与求导、极限或级数，再选具体运算。点击右侧示例会一起填入当前运算的数学输入框，例如被积函数与积分限、矩阵 A 与 B、导数的阶数与代入值。历史会恢复到对应的运算类别。

点击 `exp` 会显示 `exp()` 并把光标放在括号内，此时填写参数，例如 `exp(1)`；空括号尚不是完整表达式。选中 `x+1` 再点击 `sin`，会得到 `sin(x+1)`。点击 `( )`、`[ ]`、`{ }` 可插入一对分组括号，光标位于中间；若已选中文本，则将其包入括号中。

支持中文输入法的全角数字、英文字母、括号、逗号、分号、等号、冒号、顿号，以及 `× ÷ − π ∞` 等数学符号。数字之间的中文句号可用作小数点，例如 `１。５`。处理发生在提交计算时，不会干扰中文输入法组字。

```text
正弦（π／２）＋平方根（９）          结果为 4
指数（ｘ）                        等同于 exp(x)
力＋温度                          可搭配代入：力＝指数（０）；温度＝３
２×力＋距离＝５；力−距离＝１         方程的自动求解模式，自动识别未知数
```

常用中文函数：指数＝exp；平方根 / 根号 / 开方＝sqrt；方根＝root；自然对数＝ln；对数＝log；常用对数＝log10；正弦 / 余弦 / 正切＝sin / cos / tan；反正弦 / 反余弦 / 反正切＝asin / acos / atan；绝对值＝abs；阶乘＝factorial。常数也可写圆周率、自然常数、虚数单位、无穷大。支持这些明确的函数名与数学语法，不解析任意自然语言句子。

### 多种括号的计算顺序

`()`、`[]`、`{}` 在数学表达式中都作为分组括号，支持混合嵌套。先计算最内层，再向外计算；同层按幂、乘除、加减的顺序。全角 `（）［］｛｝` 和中文 `【】` 也支持。

```text
{2+[3*(4+1)]}                    先算 4+1，再算 3*5，再算 2+15，得到 17
2[3+{4*(5-1)}]                   省略的乘号表示相乘，得到 38
```

括号需要类型对应、顺序正确；例如 `(1+2]` 会报括号不匹配。`[]`、`{}` 在算式中不表示 Python 索引、列表或集合。矩阵页的 `[[1,2],[3,4]]` 仍表示矩阵，其元素内可继续使用分组括号，例如 `[[1+[2*3],{4+5}],[6,7]]`。

科学计算需要代入时，在同一框先写算式，再另起一行填 `x=2`、`y=pi/2`。代入是同时进行的，例如 `x=y; y=2` 不会递归把前一个 y 也替换成 2。科学计算可另起一行写 `assume: real` 或 `assume: positive` 设置变量假设，写 `digits: 20` 设置近似值精度；其他工具保留原有下拉设置。默认的一般符号不允许把 `sqrt(x^2)` 任意简化成 x。

矩阵推荐逗号分列、换行分行，元素可为数学表达式：

```text
1/2, sqrt(2), 0
0,   1,       a
2,   0,       3
```

也接受 `1,2;3,4`、`[[1,2],[3,4]]` 或 Excel 粘贴的 Tab 分隔数据。含空格的元素请使用逗号分列。矩阵右除是 `A·B⁻¹`，不是逐元素相除。LU 结果满足 `P·A=L·U`。

混合偏导栏填 `x:2,y:1`，表示先对 x 求二阶导，再对 y 求一阶导。梯度、Hessian、全微分只填变量列表，例如 `x,y`。总求导阶数最多 12。

多重积分的积分限**从内到外**排列，例如：

```text
x,0,y
y,0,1
```

表示先对 x 在 `[0,y]` 上积分，再对 y 在 `[0,1]` 上积分。对 `x+y` 的结果为 `1/2`。外层积分限不能包含已被内层积分掉的变量。

方程每行一个，未写等号时右边默认为 0。数值求根需要按未知数顺序给初值，通常只得到初值附近的一组根。

## 使用方程页

在「方程」选择求解方式。标量方程和求解条件使用同一个输入框，可在同一式中使用行列式、积分、导数、全微分、极限、级数及初等函数。级数可以用 `sum(...)` 求和，或用 `trunc(f,x,a,n)` 取级数展开的截断表达式。

自动识别求解后表达式中剩余的未知数；需要区分系数参数时，在同一框另起一行指定 `vars: x`。数值求根可另起一行写 `guess: 1` 或 `guess: 1,1`，不填写时从各变量初值 1 开始。单变量符号求根默认实数域，可写 `domain: complex` 改为复数域。多元非线性方程组仍按复数域求解。

| 输入 | 结果 |
| --- | --- |
| `integrate(t,t,0,a)=2` | `a=-2` 或 `a=2` |
| `diff(x^3,x)=12` | `x=-2` 或 `x=2` |
| `limit(sin(a*x)/x,x,0)=2` | `a=2` |
| `at(diff(a*x^2,x),x,1)=4` | `a=2` |
| `det([x,2],[3,4])+∫(t,t,0,2)=12` | `x=4` |

`det([x,2],[3,4])` 中，每对中括号是一行，计算结果是可参与普通运算的标量。`integrate(expr,t,lower,upper)` 的积分变量不能同时作为本层积分限中的变量，变上限积分需使用不同名字，例如 t 积分、x 作上限。方程中的积分必须明确上下限；一般不定积分含任意常数，应先改写为含 C 的原函数再解方程。科学计算单独调用 `integrate(expr,x)` 只返回一个原函数，通用的不定积分结果建议使用积分页，其结果显示 `+C`。

`diff(expr,x,n)` 支持 1～10 阶导数；`at(expr,x,a)` 在 x=a 处代入；`limit(expr,x,a)` 默认双侧极限，第四个参数 -1 或 1 分别为左侧、右侧。左右极限不同会报错。这些函数也有“积分、求导、导数、极限、代入”的中文别名。含微积分的计算统一使用弧度制。

### 矩阵方程

选择「方程 → 矩阵方程」，先输入 `ABC=D` 或 `A*B*C=D`，再指定要解的矩阵，例如 `B`。工具会显示 A、C、D 的输入框。与普通矩阵输入相同，同行元素用逗号分隔，矩阵各行用换行分隔。点击右侧示例可一次填齐。

旧的 `AX=B` 入口在这里也可使用。等号两侧都可有多个相乘的矩阵，例如 `U*X*V=P*Q`。每侧最多九个因子，每次求一个只出现一次的未知矩阵。工具自动推断未知矩阵的尺寸，并区分唯一解、含自由参数的解和无解。

### 常微分方程与初始条件

在「方程」选择「常微分方程」，在同一输入框写：

```text
diff(y(x),x)=y(x)
y(0)=1
```

得到 `y(x)=exp(x)`。二阶例子：

```text
diff(y(x),x,2)+y(x)=0
y(0)=0
at(diff(y(x),x),x,0)=1
```

得到 `y(x)=sin(x)`。未知函数名支持 f、g、h、y、u、v，单次只求一个未知函数的常微分方程；不提供初值时返回含任意常数的通解。偏微分方程和联立微分方程暂不支持。

### 未知函数的积分方程

在「方程」选择「积分方程（Volterra 型）」，输入：

```text
y(x)=1+integrate(y(t),t,0,x)
```

得到 `y(x)=exp(x)`，并回代原方程核对。当前支持固定有限下限、上限等于自变量、可通过至多三次求导消去积分的单函数 Volterra 型方程。例如核函数 `(x-t)*y(t)` 也支持。一般积分方程可能无法用这种方法求解，会明确提示，不会将未求出当作无解。仅给出未知函数的极限条件也不足以唯一确定函数。

## 日期计算和单位换算

「日期计算」支持公历 1601 至 9999 年。日期差为两个日期相隔的总天数，并按年、月、周、日提供日历间隔。加日期按年、月、日依次计算，减日期按日、月、年依次计算。目标月少于原日期的日数时，取目标月最后一天。例如 2024-01-31 加 1 个月得到 2024-02-29。两种模式参考 [Windows 计算器日期计算](https://support.microsoft.com/en-us/windows/apps/calculate-days-between-dates-or-calculate-a-future-or-past-date)。

「转换器」提供 Windows 计算器的 12 类非货币换算，共 132 个常规单位。输入数值并选择原单位与目标单位，结果即时更新。交换按钮用换算结果作为反向换算的输入。体积区分美制与英制，数据区分 1000 进位的十进制单位和 1024 进位的二进制单位。某些类别还会显示日常物品的估算对照。日期和换算均在浏览器内执行。单位覆盖参考 [微软计算器的单位清单](https://github.com/microsoft/calculator/blob/main/src/Calculator.ViewModels/DataLoaders/UnitConverterDataLoader.cs)。

## 图表

打开「转换器」下方的「图表」，可在一张坐标图上输入多条表达式。点表达式旁的色点可隐藏或显示对应曲线。拖动可平移，滚轮或双指可缩放。横轴和纵轴范围可分别设置。对于关于 x 的函数，点图上标记或使用「关键点」菜单可查看近似零点、极值、交点及纵截距。

「数学键盘」按符号和函数类别切换。点击某个表达式框，再点符号键即可在当前光标处插入。数字直接在表达式里输入。「示例库」可按类别浏览图形缩略图，点击后载入表达式、参数和视图范围。可撤销最近一次载入。

计算、方程和图表都有「插入公式模板」，可按分式、平方根和定积分的各个位置填写，再插入到当前光标处。计算或求解得到可绘制的结果时，可以「发送到图表」。单变量方程会画等号两边之差，零点对应方程的根。

「保存与导入」可在当前浏览器命名保存最多 30 张图。同名保存会更新原记录。JSON 文件可带走表达式、滑块、范围和视图设置，也可重新导入。数值表可导出 CSV，图像可导出 PNG。

| 示例 | 含义 |
| --- | --- |
| `y=x^2-2` 或 `f(x)=x^2-2` | 关于 x 的函数。命名函数可在其他表达式里调用，例如 `y=f(x+1)`。 |
| `x=3` 与 `(1,2)` | 垂直线与坐标点。 |
| `x^2+y^2=9` 与 `x^2+y^2<=9` | 圆周与圆内区域。 |
| `y=a*sin(b*x)` | 为 a、b 生成滑块。另起一行输入 `a=2` 可固定 a。 |
| `(3*cos(t),2*sin(t))` 与 `r=2*cos(3*θ)` | 参数曲线与极坐标曲线。可在图表设置里更改参数范围。 |
| `y=diff(sin(x),x)` 与 `y=integrate(sin(t),t,0,x)` | 导数与累积积分的数值近似。积分限为有限值。 |
| `sequence(1/n,1,10)` 与 `polyline((0,0),(1,2),(3,1))` | 数列散点与按顺序连接的折线。 |
| `regression((0,1),(1,2),(2,5))` 与 `polygon((-2,-1),(0,2),(3,-1))` | 散点及线性拟合，以及用顶点绘制的多边形。 |
| `histogram([1,1,3,4],2)`、`dotplot([1,1,3,4])` 与 `boxplot([1,1,3,4])` | 直方图、堆叠点图与箱线图。 |
| `y=x^2 {0<=x<=3}` | 只画指定范围。 |

三角函数使用弧度。`ln(x)` 和单参数 `log(x)` 为自然对数，`log10(x)` 为常用对数，`log(x,a)` 指定底数 a。`diff(f,x,n)` 的第三个参数是阶数，在指定点求导写成 `at(diff(f,x),x,a)`。绘图在实数坐标平面内完成，导数、定积分和关键点坐标采用数值近似。负数的实奇次根可用 `realroot(x,n)`。打开旧草稿时，会自动把旧写法迁移为含义等价的表达式。交互参考 [Windows 计算器绘图说明](https://github.com/microsoft/calculator/blob/main/docs/ManualTests.md) 和 [Desmos 图形计算器帮助](https://help.desmos.com/hc/en-us/articles/4406040715149-Getting-Started-Desmos-Graphing-Calculator)。

## 结果的边界

SymPy 不能解出所有数学问题。没有解析结果时，会保留 `Integral` 积分符号、条件解集或参数解；不会把未求出当成零。发散积分与无定义值会提示。超越方程数值解不是全部解，非线性方程组按复数域求解。符号化简后的结果应结合原式的定义域使用，例如 `(x^2-1)/(x-1)` 化简成 `x+1` 不会恢复原式在 x=1 的定义。

含参数矩阵按一般参数条件计算，参数取特殊值时，秩、可逆性、解的数量都可能变化；请代入具体参数后再核对。`root(x,n)` 采用主值约定，负实数的实奇次根可写成 `sign(x)*abs(x)^(1/n)`。

## 部署到 Ubuntu / VPS

### Docker

可以载入发布版镜像，也可以从仓库根目录构建。

```bash
docker load -i caveqis-1.0.0-linux-amd64.tar.gz
# 或从源码构建
docker build --platform linux/amd64 -t caveqis:1.0.0 .
```

本机访问或 VPS 配合一层 Nginx 反向代理时，可将容器端口映射到回环地址。

```bash
docker run -d --name caveqis --restart unless-stopped \
  -p 127.0.0.1:8765:8765 caveqis:1.0.0
curl http://127.0.0.1:8765/api/health
```

在本机浏览器打开 `http://127.0.0.1:8765/`。接入 Nginx HTTPS 反代时，按下方说明配置请求头，并在创建容器时增加 `-e MATH_TRUST_PROXY=1`。

### Python 与 systemd

部署需要同时提供静态页面和 Python 计算服务。运行时无需 Node.js、数据库或付费计算接口。

将本项目上传到 `/opt/math-toolbox`，不上传 Windows 的 `.venv`、开发检查目录 `node_modules`、`__pycache__` 与 tests 产生的缓存。在服务器已有 Python 3.10+ 的前提下：

```bash
sudo apt update
sudo apt install python3-venv
sudo useradd --system --user-group --home-dir /opt/math-toolbox --shell /usr/sbin/nologin mathbox
cd /opt/math-toolbox
sudo python3 -m venv .venv
sudo .venv/bin/python -m pip install -r requirements.txt
sudo chown -R root:mathbox /opt/math-toolbox
sudo chmod -R g+rX,o-rwx /opt/math-toolbox
sudo cp deploy/math-toolbox.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now math-toolbox
curl http://127.0.0.1:8765/api/health
```

如果 `mathbox` 用户已存在，跳过创建步骤。上传目录必须已包含本项目文件。服务通过 Waitress 运行，绑定 `127.0.0.1:8765`；systemd 模板默认限制服务内存 512 MB，一次只执行一个计算，计算子进程在 Linux 另有限制。实际容量仍取决于服务器其他程序和题目复杂度。

将 `deploy/nginx-tools.conf` 里的 **location 块**加入你现有域名的 `server {}` 中，访问路径为 `/tools/`，例如 `https://你的域名/tools/`。保留现有 HTTPS、端口和其他站点配置，不要把该文件覆盖整个 Nginx 配置。`/tools` 会自动转到带末尾斜杠的 `/tools/`。

```bash
sudo nginx -t
sudo systemctl reload nginx
```

如果你想把工具箱放在站点根目录，把示例中的 `location /tools/` 改为 `location /`，并去掉 `location = /tools` 块即可。前端的资源和 API 都使用相对路径，兼容这两种方式。若网站经过多层反向代理，需要按实际可信代理链重新设置，不能直接照搬单层代理模板。

模板中的 `MATH_TRUST_PROXY=1` 仅适用于**只绑定回环地址、前方恰有一层可信反向代理**的运行方式。Nginx 要覆盖 `X-Forwarded-For` 与 `X-Forwarded-Proto`，这样 HTTPS 来源校验和按访客地址限流才能正确工作。无代理直连时保持默认未启用状态。

配置环境变量：

| 变量 | 默认 | 作用 |
| --- | --- | --- |
| `MATH_TIMEOUT` | `12` | 单次计算秒数，允许 2～30 |
| `MATH_WORKERS` | `1` | 同时计算数，允许 1～2；内存较小时建议 1 |
| `MATH_TRUST_PROXY` | 未启用 | 值为 `1` 时信任一层代理的访客地址与协议 |

计算采用受限数学语法解释，不调用用户字符串的 `eval` 或 SymPy `parse_expr`；每个请求在独立子进程中计算，超时后会终止。接口包含体积限制、同源请求检查、并发限制与每个连接地址每分钟 40 次的限流。若无需对所有访客开放，可在现有 Nginx 中加入你已有的访问认证方案。

## 检查与文件

在项目目录运行：

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

输入面板的光标与选区逻辑可直接运行 `node --test tests/test_math_input.cjs`。完整界面 DOM 检查需要开发环境安装依赖后运行 `npm ci --ignore-scripts`、`npm test`；Node.js 和 node_modules 都不是工具箱运行或 VPS 部署依赖。

- `app.py`：HTTP 接口、静态页面与隔离计算进程。
- `engine.py`：受限表达式解析和 SymPy 计算。
- `equation_solver.py`：单输入框设置、代数方程、常微分方程及部分积分方程求解。
- `static/`：中文网页、样式、交互、本地 KaTeX 资源。
- `tests/`：精确运算、退化方程组、微积分、输入边界和 HTTP 集成检查。
- `deploy/`：Nginx 子路径反向代理与 systemd 服务模板。
- `Dockerfile`：浏览器版的容器构建配置。
- `desktop/`：Windows 窗口、计算引擎入口和安装包构建脚本。
- `启动工具箱.cmd` / `start.ps1`：Windows 启动入口。

技术参考：[SymPy 解析文档](https://docs.sympy.org/latest/modules/parsing.html)、[SymPy 积分文档](https://docs.sympy.org/latest/modules/integrals/integrals.html)、[Flask / Waitress 部署文档](https://flask.palletsprojects.com/en/stable/deploying/waitress/)。KaTeX 0.19.1 的 MIT 许可证位于 `static/vendor/katex/LICENSE`。

微积分和常微分方程参考：[SymPy 微积分教程](https://docs.sympy.org/latest/tutorials/intro-tutorial/calculus.html)、[SymPy 常微分方程求解指南](https://docs.sympy.org/latest/guides/solving/solve-ode.html)。
